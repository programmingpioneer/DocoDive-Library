## Important files deliberately retained

- `app.py` is the `procfile` entry point (`web: gunicorn app:app`); lack of an inbound Python import would not make it unused.
- All current CSS and JavaScript files have a literal source consumer. The shared appearance layers and component styles are not byte-identical copies.
- Root account, authentication, presentation, settings, metrics, SEO and learning modules have AST import evidence from application modules or tests.
- `scripts/ui_preview.py`, `scripts/reader_ui_preview.py`, `scripts/appearance_audit.py`, `scripts/local_route_audit.py` and tests support isolated local verification.
- `run_migration.py` and `scripts/run_all.py` are standalone maintenance workflows, not runtime imports. `LOCAL_HANDOVER.md:46` documents the latter. Neither was run.
- `static/images/Preview.png` is used by `README.md:141`; documentation is a valid consumer.
- Design references, plans, reports, manifests and prior UI evidence are intentional project records. No cleanup of those records was proposed.
- SQL, backup files, protected configuration and user uploads were left outside deletion decisions.

No additional `.tmp`, `.temp`, `.orig`, `.rej`, `.bak`, `.backup` or editor-tilde source-tree files were found in the permitted audit scope. Generated logs and screenshots in deliverables were not classified as waste or read for this audit.

## Limits

This is a local source audit. It cannot prove absence of external deployment consumers, database-stored asset URLs, historical public links or manually invoked workflows. Dynamic lesson/template dispatch was accounted for explicitly. No source removal should be inferred from a filename search alone. After any approved cleanup, check retained file paths against the candidate JSON and run the existing isolated checks as appropriate.
